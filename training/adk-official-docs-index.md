# Official Google ADK and Google AI Documentation Index

This index is the canonical reference list for the enterprise ADK playbooks in this training repository. Use these links as the source of truth for framework updates, product changes, and implementation decisions.

The aim is simple: when the core ADK capability changes, the playbooks should be updated against the official docs rather than by memory or stale examples.

## Core ADK documentation

- ADK documentation home: https://google.github.io/adk-docs/
- ADK concepts and agent model: https://google.github.io/adk-docs/agents/
- ADK tools and tool design: https://google.github.io/adk-docs/tools/
- ADK workflows and orchestration: https://google.github.io/adk-docs/workflows/
- ADK sessions and memory patterns: https://google.github.io/adk-docs/sessions/
- ADK evaluation and observability guidance: https://google.github.io/adk-docs/observability/

## How to use this in future updates

When a major ADK or Google AI capability changes, update the relevant playbook section in this sequence:

1. Check the official ADK docs listing for the relevant area.
2. Confirm any updated APIs, workflow patterns, or recommendations.
3. Update the linked official references and adjust the implementation guidance.
4. Re-run the docs build to validate the site remains healthy.

This keeps the repo aligned with the official product direction while preserving a training-friendly enterprise interpretation layer.
