> **💡 Learners vs. Contributors:**
> * **Taking the labs?** Direct clone or 1-click cloud launch gives you immediate read-only access to run all code.
> * **Contributing enhancements?** [Fork the repository](https://github.com/inderanz/google-adk-training/fork) and submit a Pull Request against `main`.
>
> **Prerequisites & Official Guidance:**
> * **API Key / GCP Project:** Grab a free key from [Google AI Studio](https://aistudio.google.com/) (`export GEMINI_API_KEY="..."`) or set up ADC via `gcloud auth application-default login`.
> * **Official ADK Guide:** [Google ADK Documentation](https://google.github.io/adk-docs/)
